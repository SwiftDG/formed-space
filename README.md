# FORMED SPACE

An original two-page editorial architecture exhibition. It is deliberately separate from the cinematic site: warm paper, oxide red, mineral green, Bodoni-led typography, asymmetrical grids, image reveals and a restrained page wipe.

## Run locally

Serve `dist` through any static HTTP server.

```bash
npx serve dist
```

Open `/` for the exhibition index and `/field-note.html` for the interior article.

## Interaction and accessibility

- Keyboard skip links and semantic navigation
- Full-page index with accessible expanded state
- Working interior-page transition
- Material filter interaction
- Pointer enhancement removed on touch layouts
- Reduced-motion styling
- Mobile layouts are recomposed rather than scaled desktop grids

## Photography

Editorial photographs are requested from Unsplash's image CDN. They are documentary architecture and interior photographs, not generated people or fake project evidence. All project descriptions are clearly labelled as imagined studies.
